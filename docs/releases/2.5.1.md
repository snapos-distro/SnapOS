Hyprland back to plain tiling, and a new home for updates.

- **Hyprland** tiles its windows again, the way it is meant to: no title bars and no minimize. The bar shows one network icon instead of two.
- **Updates come from their own repository**, [snapos-distro/snapos-updates](https://github.com/snapos-distro/snapos-updates). It holds only what `snapos update` needs, so checking for updates no longer depends on the repository with the installer images.
- **SnapOS moved to the snapos-distro organization.** Old links keep working.
- **Installer**: the new system is written to disk and unmounted before the installer says it is done.

Everything from 2.5 stays: the native Debian layer, Steam, the `snapos` commands, x86_64 and ARM64 images, four desktops, SnapGuard in real time.

Flash with balenaEtcher. Checksums in the `.sha256` files.
