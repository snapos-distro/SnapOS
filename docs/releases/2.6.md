Net install, a minimal image, and SnapOS in packs.

**Net install.** With the internet up, the installer downloads the newest SnapOS from snapos-updates, checks its checksum and installs it, so this USB stick keeps installing the latest version. Without the internet it installs the version on the stick. The review screen shows which one.

**The minimal image** (`snapos-minimal.iso`, `snapos-minimal-aarch64.iso`): a terminal and no installer. You write your own system the NixOS way and add the SnapOS packs you want. The [handbook](https://snapos-distro.github.io/handbook/) walks through every step.

**SnapOS in packs.** theme, desktops, commands, snapguard, snapweb, debian, helper and updater: each one a line in any NixOS system (`snapos.packs.theme.enable = true;`). The full SnapOS is every pack turned on. On a system built by hand, the updater updates the packs.

**SnapOS names for the NixOS tools:** `snapos-generate-config`, `snapos-install`, `snapos-enter` and `snapos-rebuild`; a hand-built system lives in `/etc/snapos`.

Everything from 2.5.2 stays: SnapGuard's cup, the native Debian layer, the `snapos` commands, four desktops, updates that undo themselves.

Flash with balenaEtcher. Checksums in the `.sha256` files.
